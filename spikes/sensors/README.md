# Fixtures históricas de adquisición

Importadas del control de Gorilla-Escape/PWA. `capture.js` reexporta la implementación mantenida en `src/input/sensors/capture.js`; `capture.test.js` se incluye desde `tests/sensors.test.js`.

Son pruebas con EventTarget y permisos/relojes de fixture, sin teléfono físico. Ejecutar `npm test` desde la raíz de este repositorio. Alcance y procedencia en [CONTROL_INTEGRATION](../../docs/CONTROL_INTEGRATION.md).
